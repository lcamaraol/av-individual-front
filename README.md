# Exercício 01 — Apresentação Pessoal

Página simples contendo:

- Nome
- Pequena descrição pessoal
- Lista de hobbies/interesses
- Imagem representativa
- Link para rede social/GitHub

### Conceitos utilizados

- Estrutura básica HTML
- Tags semânticas
- Estilização com CSS
- Margin e Padding
- Cores e imagens

---

# Exercício 02 — Card de Produto

Criação de cards de produtos para uma loja virtual contendo:

- Imagem do produto
- Nome
- Descrição
- Preço
- Botão de compra

### Recursos adicionados

- Efeito hover nos cards
- Botão com animação
- Layout responsivo
- Glassmorphism (efeito desfocado)
- Flexbox

---

# Exercício 03 — Layout com Flexbox

Desenvolvimento de um layout utilizando Flexbox para alinhamento e organização dos elementos na página.

### Conceitos utilizados

- display: flex
- justify-content
- align-items
- gap
- flex-wrap
